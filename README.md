# SSPI PS4

Minimal application source export for Super Simple Package Installer.

This repository contains the application implementation, project manifests and license notices. The banner is the only published artwork. It does not contain SDKs, runtime assets, provider/source recipes, recorded website pages, test fixtures, internal documentation or build/release tooling.

The complete working project and local build inputs remain in the SSPI-DEV development workspace. This source export alone is not a turnkey distribution build; excluded inputs must be supplied separately. Existing local builds continue to use the ignored build scripts and SDK folder, with output under `../Build-Output/PS4/`.

See LICENSE and THIRD_PARTY_NOTICES.md for source notices. The Git allowlist intentionally excludes everything outside the selected code and metadata files.
